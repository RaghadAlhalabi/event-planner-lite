# Event Planner Lite – User Guide
## 🚀 Live Application

The application is deployed and available online:

👉 **https://event-planner-lite-1.onrender.com**

## 📌 Overview

Event Planner Lite is a simple application that allows users to:

* Create an account
* Manage personal events
* Send invitations
* Respond to invitations (RSVP)

---

## 🟣 1. Create Account & Login

When you open the application, you will see:

* **Login**
* **Create Account**

⚠️ **Note:**
Sometimes only the login form appears. Refresh the page to display the **Create Account** section.

### Create a new account:

1. Enter your email address
2. Enter your display name
3. Enter a password (at least 8 characters)
4. Accept:

   * Terms of Service
   * Privacy Policy
5. Click **Create Account**

After that, you can log in using your credentials.

---

## 🟢 2. Account & Profile

After logging in, you can:

* View your personal information
* Log out (**Logout**)
* Refresh your profile (**Refresh Profile**)
* Delete your account (**Delete Account**)

---

## 📅 3. Create Event

To create a new event:

1. Enter the event title
2. Select the start date and time
3. Select the end date and time
4. Enter the location
5. Add notes
6. Click **Create Event**

The event will appear immediately after creation.

---

## ✏️ 4. Manage Event

After creating an event, you can:

* Edit the event (**Edit**)
* Delete the event (**Delete**)
* Manage invitations (**Invitations and RSVPs**)

---

## 📩 5. Send Invitations

To send an invitation:

1. Click **Invitations and RSVPs**
2. Enter the guest’s email address
3. Click **Send Invitation**

An email invitation will be sent to the guest.

---

## 📧 6. Invitation Email

The guest will receive an email containing:

* Event name
* Date and time
* Location
* Invitation link

⚠️ **Note:**
The email may appear in the **Spam/Junk** folder the first time.

---

## 🔐 7. Open Invitation

When opening the invitation link:

* If the user already has an account → **Login**
* If not → **Create Account**

---

## ✅ 8. RSVP (Respond to Invitation)

The invited user can:

1. Choose a response:

   * Yes
   * No
   * Maybe
2. Write a note
3. Click **Save RSVP**

---

## 🔄 9. View Responses (For Event Owner)

The event owner can:

1. Click **Refresh RSVPs**
2. View guest responses
3. Read their notes

---

## 💡 Notes

* Refresh the page if some elements do not appear
* Check the Spam/Junk folder for invitation emails
* Events can be edited or deleted at any time
